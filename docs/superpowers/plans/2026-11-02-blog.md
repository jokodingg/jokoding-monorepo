# Blog `/blog` jokoding.id Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Markdown-driven blog at `jokoding.id/blog` whose post pages are prerendered to static HTML with full SEO meta, embedding YouTube videos.

**Architecture:** Same Vite + React app. `react-router-dom` adds `/blog` and `/blog/:slug`. Posts are `.md` files loaded with `import.meta.glob`. A second `vite build --ssr` plus `scripts/prerender.js` writes static HTML for blog routes and `sitemap.xml`. Home stays client-rendered.

**Tech Stack:** React 18, Vite 5, Tailwind v4 (`@tailwindcss/vite`), vitest 3, `react-router-dom@^7`, `front-matter`, `marked`, `@tailwindcss/typography`. pnpm workspace + Turborepo.

**Spec:** `docs/superpowers/specs/2026-11-02-blog-design.md`

All paths below are relative to `apps/jokoding.id/` unless they start with `docs/`. Run commands from `apps/jokoding.id/`.

## Global Constraints

- Site URL constant: `https://jokoding.id`. Canonical URLs have no trailing slash: `https://jokoding.id/blog`, `https://jokoding.id/blog/<slug>`.
- Post title format: `<judul post> | Blog Jokoding`. Blog index title: `Blog | Jokoding`.
- Blog index description and intro sentence: `Video dan tulisan Jokoding seputar AI, web, IoT, dan dunia coding.`
- Home title (restore on client nav back to `/`): `Jokoding - Jasa Joki IT & Aplikasi Profesional Semarang`.
- Default cover when `cover` is empty: `https://i.ytimg.com/vi/<youtubeId>/hqdefault.jpg`. If no `youtubeId` either (draft), cover is `null`.
- Default `og:image` when cover is `null`: `https://jokoding.id/og-image.jpg`.
- YouTube iframe URL: `https://www.youtube-nocookie.com/embed/<id>?autoplay=1`.
- Date display: `2 November 2026` (Indonesian month names, `timeZone: 'UTC'`).
- Validation error format: `content/blog/<file>.md: "<field>" wajib diisi` (and similar, always prefixed with the relative file path).
- Slug rule: `/^[a-z0-9-]+$/`.
- Drafts: visible when `import.meta.env.DEV`, hidden otherwise.
- UI copy is Indonesian. Code comments follow the existing Indonesian style.
- Do not touch the repo root `.gitignore`; it carries an unrelated uncommitted change by the user.

## Review Focus

1. **YAML dates.** `front-matter` (js-yaml) turns `date: 2026-11-02` into a JS `Date`, not a string. Expected: `post.date === '2026-11-02'`. Test in Task 1.
2. **Timezone drift in displayed date.** Build runs in UTC, viewers may be in UTC−X. Without `timeZone: 'UTC'`, server and client render different days and hydration breaks. Expected: `formatDate('2026-01-01') === '1 Januari 2026'`. Test in Task 1.
3. **Hostile characters in meta and JSON-LD.** A description containing `"`, `<`, `&` or `</script>` must not break the head. Expected: attributes escaped, JSON-LD has `<` as `\u003c`. Test in Task 2.
4. **Relative cover path in `og:image`.** Crawlers need absolute URLs. Expected: `cover: /blog/x.jpg` gives `https://jokoding.id/blog/x.jpg`, an `https://` cover stays as is. Test in Task 2.
5. **SSR bundle import in plain Node.** Some deps (for example `react-fast-marquee`) may be CommonJS and fail on named imports when `dist-server/entry-server.js` is imported. Expected: `node scripts/prerender.js` succeeds. Covered by the build + smoke steps in Task 6; fix with `ssr.noExternal` if needed.
